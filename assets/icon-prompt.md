# Transcriber icon

Source: `AppIcon.png`, with a transparent background. A blue rounded square contains a white audio waveform flowing into lines of text. ICNS is generated with the standard `sips` and `iconutil` tools.

## Prompt

Use case: logo-brand. Asset type: square macOS application icon for Transcriber, an audio-to-text utility. Primary request: a clear, restrained, professional icon conveying recorded audio becoming written text. Subject: a bold white audio waveform flowing into three clean horizontal white text lines, arranged as a single balanced symbol. Style: crisp minimal flat shapes with a subtle polished macOS finish, generous contrast and readability at 32 pixels. Composition: centered mark inside a blue rounded-square tile, generous safe margins; the complete tile is visible. Outside the rounded tile is genuinely transparent. No characters, faces, eyes, mascots, letters, words, watermark, extra objects or busy decoration. Produce one square icon.
